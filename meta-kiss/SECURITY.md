How to Report a Potential Vulnerability
=======================================

If you would like to report a public issue (for example, one with a released
CVE number), please report it using the
[Github Issues page](https://github.com/bootlin/yocto-kiss/issues).

If you are dealing with a not-yet released or urgent issue, please send a
message to info AT bootlin DOT com, including as many details as possible: the
layer or software module affected, the recipe and its version, and any example
code, if available.
